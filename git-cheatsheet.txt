Шпаргалка по Git — Максим Шкурский

git init -b main — инициализировать локальный репозиторий с главной веткой main
git status — проверить состояние файлов и репозитория
git add <файл> — добавить изменения файла в индекс (подготовить к коммиту)
git commit -m "сообщение" — зафиксировать изменения в истории (создать коммит)
git log --oneline — посмотреть краткую историю коммитов
git branch — посмотреть список локальных веток
git switch -c <имя_ветки> — создать новую ветку и перейти на неё
git switch <имя_ветки> — переключиться на существующую ветку
git remote add origin <ссылка> — привязать удаленный репозиторий GitHub
git push -u origin <имя_ветки> — отправить ветку на GitHub с привязкой
git branch -a — показать все ветки (локальные и удаленные)
